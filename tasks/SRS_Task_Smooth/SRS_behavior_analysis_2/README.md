# SRS_Task_Smooth behavioral analysis

This folder contains a standalone MATLAB analysis pipeline for the `trialXXXX.mat` files generated by `SRS_Task_Smooth`. It does not require `pds.loadP`, does not modify raw PLDAPS files, and separates simulated/debug choices from real eye-controlled choices.

## Quick start

1. Extract the complete `SRS_behavior_analysis` folder to a permanent location.
2. Open MATLAB and set the **Current Folder** to `SRS_behavior_analysis`.
3. Run `SELF_TEST_UPLOADED_SESSION.m` once on the reference session.
4. Open `RUN_ONE_SRS_SESSION.m`, edit `sessionFolder`, and click **Run**.
5. Use `RUN_ALL_SRS_SESSIONS.m` to analyze all sessions and create a combined dataset.

Generated outputs are centralized inside this analysis folder:

```text
SRS_behavior_analysis/
├── figures/
│   └── <session_name>/
│       ├── 01_online_plots_with_statistics.png
│       ├── 01_online_plots_with_statistics.pdf
│       ├── 01_online_plots_with_statistics.fig
│       └── ...
└── results/
    └── <session_name>/
        ├── trial_table.csv
        ├── analysis_report.txt
        ├── analysis_results.mat
        └── statistical CSV files
```

The raw session directory is never used as an output directory.

## Statistical notation shown on figures

Statistical results are displayed directly on the figures:

- `ns`: p or q ≥ 0.05
- `*`: p or q < 0.05
- `**`: p or q < 0.01
- `***`: p or q < 0.001

Families of related exploratory tests are corrected with the Benjamini-Hochberg false-discovery-rate procedure. Stars use the resulting `QFDR` values when available. The exact raw p-values and corrected q-values are saved in the CSV files and written in `analysis_report.txt`.

Single tests that are not part of a multiple-test family, such as the conflict-versus-congruent RT permutation test and the psychometric logistic-slope test, are displayed using their raw p-values.

## Main MATLAB files

### `RUN_ONE_SRS_SESSION.m`

Daily entry point for one session. It contains the session path and the main settings: permutation count, rolling-window length, and figure export formats.

### `RUN_ALL_SRS_SESSIONS.m`

Analyzes all detected sessions separately and then creates a combined analysis. Sequential dependencies are calculated within each session, so no artificial transition is created between recording days.

### `SELF_TEST_UPLOADED_SESSION.m`

Regression test based on `20260720_t1112_srsSmooth_training`. It checks expected trial counts, derived variables, statistical outputs, and the new folder structure.

### `srs_load_session.m`

Reads every `trialXXXX.mat` file and creates one table row per saved attempt. Derived fields include:

- success or failure
- instruction, conflict, or congruent condition
- T1/T2 identity and side
- rich and high-salience targets
- identity and spatial choice
- reward-guided and salience-guided choice
- identity and spatial stay/switch variables
- reward, hue contrast, and luminance differences
- saccadic reaction time
- fixation-acquisition latency
- saccade and trial duration
- pre-trial interval
- block position and debug flags

A choice enters behavioral inference only when `RealEyeChoice=1`, corresponding to `passEye=0` and `mouseEyeSim=0`.

### `srs_compute_statistics.m`

Computes:

- session quality and completion
- experimental counterbalancing checks
- right/left and T1/T2 biases
- rich-target and high-salience-target preferences
- spatial and identity perseveration
- 16 candidate deterministic strategies
- exact conditional associations from 2×2 tables
- direct conflict-versus-congruent choice comparisons
- early-versus-late policy changes
- binned psychometric data
- an unbinned logistic psychometric fit implemented without a toolbox
- reconstructed online-choice statistics
- conflict-versus-congruent reaction-time statistics
- previous-reward stay/switch analysis
- block completion
- temporal trends
- operational engagement and change-point tests
- optional multivariable logistic models when `fitglm` is available
- Benjamini-Hochberg FDR corrections within each test family

### `srs_make_figures.m`

Creates five figure windows. Each window contains a detailed explanatory caption inside the figure, so it remains visible in MATLAB and in exported PNG/PDF files.

#### Figure 1: online plots with statistics

- signed T1−T2 reward difference
- signed T1−T2 salience evidence
- conflict/congruent choice proportions with Wilson confidence intervals
- exact tests against 0.5
- Fisher exact comparisons between conditions
- cumulative high-salience choices
- individual RTs, medians, and permutation test
- previous-reward stay/switch analysis

#### Figure 2: strategy diagnostics

- candidate-strategy prediction accuracy and exact tests against chance
- spatial choice sequence
- T1/T2 identity sequence
- conditional spatial influences with Fisher exact tests
- blockwise policies
- rolling right/left entropy

#### Figure 3: operational engagement and quality

- trial outcomes
- rolling completion rate
- pre-trial intervals
- fixation-acquisition latency
- saccadic reaction time
- missed frames
- block stopping points
- attempt duration
- permutation-corrected change-point p-values

This figure does not measure subjective boredom. It only identifies observable changes in task engagement.

#### Figure 4: additional inferential analyses

- binned psychometric points with Wilson intervals
- unbinned logistic psychometric curve and slope test
- first-third versus last-third policy changes
- conditional effect sizes and Fisher tests
- correlations with attempt number and permutation tests

#### Figure 5: compact statistical summary

- core biases with confidence intervals and exact tests
- direct conflict-versus-congruent comparisons
- multivariable logistic odds ratios when available
- numerical engagement results and change-point tests

### `srs_write_report.m`

Creates an English `analysis_report.txt` containing descriptive results, p-values, FDR-adjusted q-values, effect sizes, odds ratios, confidence intervals, block completion, engagement tests, and a guide to every figure.

## Interpretation constraints

The candidate-strategy analysis cannot distinguish policies that make identical predictions in the current design. For example, if T2 remains rich for an entire block, “always T2” and “choose the rich target” are confounded. Rich-target identity must reverse across blocks and sides must remain counterbalanced.

These analyses are exploratory. Confirmatory conclusions require prespecified hypotheses, adequate counterbalancing, replication across sessions, and a statistical model that accounts for repeated trials from the same animal.

## Compatibility

The code targets MATLAB R2019b or later. Core analyses use base MATLAB. `fitglm` adds multivariable logistic models when the Statistics and Machine Learning Toolbox is installed. The unbinned psychometric logistic fit does not require that toolbox.

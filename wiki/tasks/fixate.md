# fixate

The simplest eye task in the repo. A fixation point appears, and the subject earns a
reward by looking at it and holding gaze inside the window for a randomly drawn duration.
Its main use is fixation training and checking eye-tracker calibration. The settings
file was built from the [scd](scd.md) template: its header still says "scd", and it
keeps many scd stimulus variables (feature deltas, stimulus locations, cue timings,
per-location hit/correct-reject status counters) that the fixate state machine does not
read.

## Trial flow

`trialBegun → showFix → dontMove → hit` (reward + high tone), or `fixBreak` (low tone) or
`nonStart` (no fixation within `fixWaitDur` = 5 s). In `dontMove`, the trial succeeds
once `timeNow − fixAq > fixDurReq`. The other states in `p.state` (`holdJoy`,
`makeDecision`, `joyBreak`, `cr`, `miss`, `foilFa`, `fa`) come from the template and are
not entered by `fixate_run.m`. The experimenter display shows grid, gaze, fixation window
and a joystick indicator.

## Conditions / trial structure

There is no trial array: `initTrialStructure` and `generateStimuli` are commented out of
`_init` and `_next`. Each trial, `supportFunctions/nextParams.m` draws
`fixDurReq ~ U(fixDurReqMin, fixDurReqMax)` (0.2–0.4 s) and shows it in the GUI status
as `fixDurReq`.

## Key trVars

GUI variables: `rewardDurationMs` (300), `rewardDelay`, `fixDurReqMin/Max`,
`fixWinWidthDeg/HeightDeg` (6 × 6 dva), `fixDegX/Y`, `fixPointLinePix` (12) and
`fixPointRadPix` (20), which change the size of the fixation point between trials,
`passJoy` (1) and `passEye` (0). `useQuest = false`, and `_finish` calls
`updateQuest`.

## Data & strobes

Per-trial `trData` (eye/joystick traces, timing, `trialEndState`, `strobed`,
`missedFrameCount`) is saved with `pds.saveP`. Behavioral events are strobed with
`strobeNow` (`trialBegin`, `fixAq`, `hit`, `fixBreak`, `nonStart`), and `fixOn` is
strobed after its flip. `p.init.strobeList` is built with `fliplr` so the column order
comes out as code name, expression. It strobes only the date and time
(`date_1yyyy`, `date_1mmdd`, `time_1hhmm`), and there is no task code. `actions/` holds
`summarizeBehaviorBasic` with its helpers (`analyzeBehaviorBasic`,
`mkfig.behaviorBasic`, hit/foil-FA plots), which come from the template.

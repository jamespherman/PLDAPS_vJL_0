# scd

"scd" stands for **stimulus change detection** (header of `scd_settings_satInc.m`). The
stimuli are checkerboard-textured Gabor patches that vary in several feature dimensions
(speed, contrast, orientation, spatial frequency, saturation, luminance, hue), and any of
these can change. The monkey holds a joystick and fixates. A ring cues one of two patch
locations, and the monkey must release the joystick when the **cued** patch changes and
keep holding when the foil patch changes or nothing changes. The one settings file here,
`scd_settings_satInc.m` (`exptType = 'saturationIncrease'`), uses saturation increases as
the only change. [nfl](nfl.md) runs the same code with more settings variants.

## Trial flow

States are listed in the generated block below. A trial runs `trialBegun` → `waitForJoy`
(joystick press within `joyWaitDur`) → `showFix` (fixation point on; fixation must be
acquired within `fixWaitDur` while the joystick stays held) → `dontMove`. During
`dontMove`, events happen at times measured from fixation acquisition:

- the cue ring appears at `fix2CueIntvl` and stays for `cueDur`;
- the patches appear at `fix2StimOnIntvl = fix2CueIntvl + cueDur + cue2StimItvl`;
- the change (cue, foil or "no change") comes at `cueChangeTime` / `foilChangeTime`, each
  `stim2ChgIntvl + chgWinDur*rand` after stimulus onset. At that moment the state moves to
  `makeDecision`.

In `makeDecision`, a release between `joyMinLatency` and `joyMaxLatency` after a cued change
is a `hit` (reward `rewardDelay` after the change). A release in that window after a foil
change is `foilFa`. Holding past the window gives `miss` (cued change) or `cr` (foil/no
change). A CR is rewarded at a random `corrRejRwdTime`. An early release during stimulus
presentation is `fa`; a release before that is `joyBreak`. A fixation break is `fixBreak`.
Visual event times (`fixOn`, `cueOn`, `cueOff`, `stimOn`, `cueChg`, `foilChg`, `noChg`,
`stimOff`) are assigned by the postFlip mechanism in `drawMachine`
([drawing and postFlip](../concepts/drawing-and-postflip.md)).

## Conditions / trial structure

`initTrialStructure` builds `p.init.trialsArray` from a table chosen by `p.init.exptType`.
The columns are cue side, number of patches, cue/foil present, which patch changes, one
flag per feature, `primary` (which patch starts at `hueInit` and which at `hueInit+180`),
the number of repetitions, `trialCode` (23001–23020), and per-trial `trial seed` / `stim seed`.
For `saturationIncrease` (`tableDefSatInc`), a block holds single-patch and two-patch trials
on both cue sides: cued changes, foil changes and no-change trials, 72 trials in all.

`nextParams/chooseRow` uses up the block in a fixed order: cue side 1 single-patch, then
cue side 1 two-patch, then cue side 2 single-patch, then cue side 2 two-patch. Within each
group the order is shuffled, so the cue side stays the same for long runs. Aborted trials
(end state 11–19) stay available. When the block is empty, `updateTrialsList` builds a new
trials array with fresh seeds. `rng(trialSeed)` makes each trial's parameters reproducible.
Gabor orientation is randomized on every trial.

## Key trVars

GUI-exposed: `rewardDurationMs`, `satDelta` (0.038), `contInit`, `orientInit`, `freqInit`,
`satInit` (0.1), stimulus eccentricity/elevation for locations 1 and 2 (10° at 0° and 180°),
`passJoy`, `passEye`. Timing: `cueDur` 0.133 s, `cue2StimItvl` 0.567 s, `stim2ChgIntvl` 1 s,
`chgWinDur` 3 s, `joyMinLatency` 0.2 s, `joyMaxLatency` 0.8 s. `useQuest` is false.
The CLUT is loaded per rig: `initClut` builds `LUT_VPIXX_rig<N>` from `p.init.pcName`
([color and calibration](../concepts/color-and-calibration.md)).

## Data & strobes

The end-of-trial list in `scd_settings_satInc.m` (wrapped in `fliplr`; full table in the
generated block) strobes:

- session date and time (`date_1yyyy`, `date_1mmdd`, `time_1hhmm`);
- trial-type flags (`isCueChangeTrial`, `isFoilChangeTrial`, `isNoChangeTrial`);
- stimulus eccentricities ×10 and elevations;
- `rewardDuration`, `trialCount`, `goodTrialCount`;
- `uniqueTaskCode_scd`, `cueStimIsOn`, `foilStimIsOn`, `trialCode`, `trialSeed`, `stimSeed`.

During the trial, `scd_run.m` strobes `trialBegin`, `joyPress`, `fixOn`, `fixAq`, `cueOn`,
`cueOff`, `stimOn`, `cueChange` / `foilChange` / `noChange`, `joyRelease`, `fixBreak`,
`nonStart`, `stimOff` and `trialEnd`; reward is strobed by `pds.deliverReward`.
`scd_next.m` copies the whole stimulus structure into `p.trVars.stim` each trial.
`p.trData` also keeps `onlineEyeX/Y`, `flipTime` and `missedFrameCount`. There is no data
dictionary for this task.

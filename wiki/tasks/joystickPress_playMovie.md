# joystickPress_playMovie

This directory is a copy of [joystickPress](joystickPress.md). Its quintet files keep the
**same names**: `joystickPress_settings.m`, `joystickPress_run.m`, and so on, with
`p.init.taskName = 'joystickPress'`. You choose between the two tasks by picking the
settings file in the right folder. The trial logic is unchanged: press, hold for
`joyPressReq`, then reward. Several things are added on top of it:

- **Movie playback.** The settings file lists `p.draw.movie.movieDir`
  (`/home/herman_lab/Videos/`) and picks one file at random. `movieInit` opens it and
  computes a destination rect if the movie is larger than the screen. `_next` sets the
  movie time index and starts `Screen('PlayMovie')` along with the DataPixx microphone and
  audio schedules. `drawMachine` draws the current movie frame on every flip and rewinds
  to 0 when the movie ends. `_finish` stops playback and stores the time index, so the
  next trial resumes from the same point.
- **Ripple and PSTH.** `_init` calls `pds.initRipple`. `_finish` calls `pds.getRippleData`
  when channels are recording, then `alignSpikes`. `alignSpikes` creates a `PSTH_plotter`
  app on first use and maps strobed event codes from `p.trData.eventValues` to timing
  fields (see [online plotting](../concepts/online-plotting.md)).
- **Opto timing.** `nextParams` sets `isOptoStimTrial = rand > 0.5` and
  `optoStimTime = rand·joyPressReq`. During `holdJoy`, when `optoStimTime` has passed,
  the run either calls `pds.deliverOptoStim` or logs `timing.optoStimSham` and strobes
  `optoStimSham`. The DAC channel `p.rig.dp.optoDacChan` is zeroed afterwards and again
  at trial end.
- **Online gaze velocity.** `onlineGazeCalcs` stores `[x y t vel]` in
  `p.trData.onlineGaze` on each loop iteration, using `eyeVelFiltTaps`.

## Trial flow

This is the same as [joystickPress](joystickPress.md): `waitForJoy` → `holdJoy` → `hit`
or `miss`, with `nonStart` after `joyWaitDur`. Unlike the parent, `waitForJoy` does not
check that `joyPress` is still −1, and it prints joystick state to the command window.

## Key trVars

The defaults differ from joystickPress: `joyPressReqMin/Max` = 3/6 s,
`rewardDurationMs` = 300, `passJoy` = 1, `p.audio.pcPlayback = true`,
`connectRipple = true`, and `optoStimDurSec` / `optoPulseAmpVolts` (4.2 V).
`trDataInitList` adds `spikeTimes`, `spikeClusters`, `eventTimes`, `eventValues`,
`timing.optoStim` and `timing.optoStimSham`.

## Data & strobes

The strobeList (built with `fliplr`) holds only the date and time codes. The event strobes
are those of joystickPress plus `optoStimSham` and whatever `pds.deliverOptoStim` strobes.
The Ripple spike and event data for each trial are stored in `p.trData`.

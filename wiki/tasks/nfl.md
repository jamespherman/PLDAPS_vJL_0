# nfl

`tasks/nfl/` is a second copy of the [scd](scd.md) stimulus change detection task. Its
quintet files are still named `scd_*.m`, and every settings file sets
`p.init.taskName = 'scd'`. The task logic is the same as scd: hold the joystick, fixate,
and release when the cued patch changes. Read the [scd](scd.md) page for the trial flow,
timing variables and outcomes. This directory adds settings variants whose trial tables
change from block to block (saturation-increase blocks and contrast-increase blocks) and
repeat each condition (`initTrialStructure` comments this as "repeats of trial conditions
(reverse-correlation purposes)"). The [family page](family-scd.md) has a table of the
code differences from `tasks/scd/`.

## Trial flow

The same as [scd](scd.md#trial-flow). States are in the generated block below. The
experimenter-display fixation window is orange on contrast-change trials (except in
`nfl_shortBlocks`), green on cued changes, red on foil changes and black on no-change
trials. With `passJoy`, a trial in `makeDecision` with the joystick still held becomes a
`hit`.

## Conditions / trial structure

Each settings file picks a trial table through `p.init.exptType`. `initTrialStructure` and
`updateTrialsList` then use it as follows:

| Settings file | `exptType` | Trial tables |
|---|---|---|
| `scd_settings_nfl.m`, `scd_settings_nflNoSgl.m` | `nfl` | block 1: saturation increases only, two-patch (`tableDefSatInc_noSingle`); later blocks: 66% saturation / 33% contrast increases (`tableDef_66SatInc_33CtstInc_noSingle`) |
| `scd_settings_nflNoSgl_50.m` | `nfl_50` | block 1 as above; later blocks 50/50 saturation/contrast (`tableDef_50SatInc_50CtstInc_noSingle`) |
| `scd_settings_nflNoSgl_shortBlocks.m` | `nfl_shortBlocks` | odd blocks: short saturation-increase block; even blocks: short contrast-increase block |
| `scd_settings_satInc.m` | `saturationIncrease` | `tableDefSatInc` (single- and two-patch) |
| `scd_settings_satIncNoSgl.m` | `saturation increase no single` | `tableDefSatInc_noSingle` |
| `scd_settings_fourStimTest.m` | `fourStimTest` | four patches, saturation increase (`tableDef_fourStimTest`) |
| `scd_settings_nfl_eachChangeOnce.m` | `feature_changes` | no matching case; falls to `tableDefault` |
| `scd_settings.m` | `full_noNoEmptyCue` | no matching case; falls to `tableDefault` |

For `nfl`, `nfl_50`, `nfl_shortBlocks` and `saturation increase no single`, the initial
trials array is duplicated (`repmat(trialsArray, 2, 1)`). The `updateTrialsList.m` in this
directory duplicates every regenerated block. Rows are chosen in the same cue-side order
as scd (`nextParams/chooseRow`). `generateStimuli` sets `p.trVars.nPatches` from the number
of stimuli in the current trials-array row.

## Key trVars and settings variants

Most variants share `satDelta` 0.047, `rewardDurationMs` 350, stimuli at 10° eccentricity
at 0° and 180°, and `rigConfig_rigB_20190324`. `scd_settings.m` is older: it uses
`rigConfig_rigB_20180802.m`, `satDelta` 0.1, and a strobeList with `cueRadius`/`cueTheta`.
The contrast feature is named `ctrst` in `scd_settings.m`, `_satInc` and `_fourStimTest`,
and `cont` in the other variants (`p.stim.featureValueNames`, `*Delta`, `*Init`).
`nflNoSgl` differs from `nfl` only in its strobeList (next section).

## Data & strobes

The variant settings files write their strobeLists as `fliplr({'valueExpr', 'codeName'; …})`.
The primary `scd_settings.m` uses the same `{'valueExpr', 'codeName'}` column order without
`fliplr`, so the generated block above (parsed from it) shows the columns swapped; the
[strobe registry](../reference/strobe-codes.md#integrity-checks) lists those names. `scd_settings_nfl.m` strobes:

- trial-type flags;
- stimulus eccentricity and elevation for both locations;
- `rewardDuration`, `trialCount`, `goodTrialCount`, `taskType` (= `p.init.taskType`);
- `cueStimIsOn`, `foilStimIsOn`;
- `trialType` (column 9 of `p.init.trialsArray`, the `saturation` change flag);
- `trialSeed`, `stimSeed`.

The other variants differ as follows:

- `_nflNoSgl`, `_nflNoSgl_50`, `_nflNoSgl_shortBlocks` and `_nfl_eachChangeOnce` replace
  `taskType` with `taskCode` = `uniqueTaskCode_nfl`, rename the column-9 strobe
  `trialCode`, strobe the seeds as `randSeedTrial`/`randSeedStim`, and add
  `isContrastChangeTrial`.
- `_satIncNoSgl` strobes `taskCode` = `uniqueTaskCode_scd`, keeps the name `trialType`,
  and uses `randSeedTrial`/`randSeedStim`.
- `_satInc` and `_fourStimTest` strobe `taskType` and `trialType` and do not strobe the
  seeds. In-trial strobes are the same as in [scd](scd.md#data--strobes).
`p.trVars.stim` holds the full stimulus structure on every trial. There is no data
dictionary.

# joystick_release_for_fix_and_stim_dim

This step moves the detection target from the fixation point to the periphery. A dynamic
checkerboard patch (`generateStimuli`) appears at one of four locations while the subject
fixates. On change trials the patch dims (luminance step `lumDelta`). On a random subset
of those trials the fixation point dims at the same moment, which helps transfer the
learned "release on fixation dim" response to the peripheral patch. The subject releases
the joystick on change trials and keeps holding on no-change trials, as in
[joystick_release_for_fix_dim](joystick_release_for_fix_dim.md).

## Trial flow

`waitForJoy` → `showFix` → `dontMove` → (`makeDecision`) → outcome.

- During `dontMove`, the patch turns on at `fix2StimOnIntvl` after `fixAq` (`stimOn` is
  timed by postFlip and strobed); onset is only triggered before `fix2StimOffIntvl`. Once on,
  the patch is drawn until its frame sequence (`stimFrames`, spanning
  `stimDur = fixDurReqMax + joyMaxLatency`) runs out.
- At `fixDurReq` after `fixAq`: on a change trial, the run logs `fixHoldReqMet` and goes
  to `makeDecision`. The fixation point also switches to the dim CLUT slot unless
  `isStimDimOnlyTrial`. The patch's own luminance change is built into its frame sequence
  (epoch 2 of the stimulus arrays starts at the same time). On a no-change trial with the
  joystick held, the run strobes `cr` and gives reward.
- `makeDecision`, `hit`, `miss` and `fa` follow the fix_dim rules: `joyMinLatency` /
  `joyMaxLatency`, `reactionTime = time − fixHoldReqMet`, and reward `rewardDelay` after
  `fixHoldReqMet`.

## Conditions / trial structure

`initTrialStructure` builds a trials array with 19 columns (`cue loc`, `n stim`,
`stim1..4 on`, `stim chg`, seven feature flags, `primary`, `no of trials`, `trialCode`,
`trial seed`, `stim seed`). The table is chosen by `p.init.exptType`. The four settings
files are identical except for `exptType`, which selects one of these tables:

| Settings file | Table | Change : no-change rows per location |
|---|---|---|
| `_settings_1000.m` | `tableDef_fixAndStimDim_1000` | 9 : 0 (all change) |
| `_settings_9010.m` | `tableDef_fixAndStimDim_9010` | 9 : 1 |
| `_settings_7030.m` | `tableDef_fixAndStimDim_7030` | 7 : 3 |
| `_settings_6040.m` | `tableDef_fixAndStimDim_6040` | 6 : 4 |

Every row shows a single patch at the cued location (`n stim` = 1). Every row sets the
orientation flag; change rows also set the luminance flag for that location. `chooseRow` draws rows at random
without replacement within a block.

`nextParams` then works out the rest of the trial:
- `isChangeTrial = (stim chg ≠ 0)`. On change trials, `dimVal` is drawn from
  `low/mid/highDimVal` (all 0.8 by default), and
  `isStimDimOnlyTrial = rand < propPeriphDimOnly` (0.5). The fixation dim colour is
  written into the CLUT as in fix_dim.
- `fixDurReq` is drawn from [`fixDurReqMin`, `fixDurReqMax`] (0.5–1 s), with 0.5 s added
  on no-change trials. `fix2StimOnIntvl = 0.25·fixDurReq`, and
  `fix2StimOffIntvl = fixDurReqMax`.
- Patch geometry: location 1 is at `stimLoc1Elev` / `stimLoc1Ecc` (21°, 10 deg). The
  others sit at +90/180/270° unless `stimLoc2..4Elev/Ecc` are non-zero. Hue and
  orientation are offset per patch, rotated by `primary`.

## Key trVars

`ctrstInit = 0.35`, `satInit = 0` (achromatic patches, per commit 7a6e18ff), `lumInit = 0.3`,
`lumDelta = −0.3`, `orientDelta = 50`, `nPatches = 4`, `stimRadius = 3.25` deg,
`boxSizePix = 24`. The GUI shows `rewardDelay`, `fixDurReqMin/Max`, `stimLoc1Elev`,
`mid/highDimVal`, `propPeriphDimOnly`, `joyMinLatency` / `joyMaxLatency` and `passJoy` /
`passEye`.

## Data & strobes

- `p.trData.dimVal`, `p.trVars.isChangeTrial`, `isStimDimOnlyTrial`,
  `currentTrialsArrayRow`, `p.stim.*Array` (the per-patch feature values for each epoch),
  and timing (`stimOn`, `fixHoldReqMet`, `joyRelease`, `reactionTime`).
- strobeList: date and time only. The `trialCode` column (23001 in every row) is not
  strobed by this task.

# joystickPress

This is the first step of the [joystick family](family-joystick.md). The subject presses
the joystick and holds it for a required duration (`joyPressReq`), then gets a reward and a
high tone. There is no fixation requirement and no visual stimulus. The `drawMachine` draws
only experimenter-display items (grid, gaze dot and joystick bar), all in CLUT entries that
appear as background on the subject's screen. The many stimulus variables in the settings
file (`*Delta`, `*Init`, `stimLoc*`) come from the [scd](scd.md) template and play no role
in this task.

## Trial flow

`trialBegun` → `waitForJoy` → `holdJoy` → `hit`. The full state list is in the generated
block below.

- `waitForJoy`: a press strobes `joyPress` and goes to `holdJoy`. If there is no press
  within `joyWaitDur` (5 s), the trial ends as `nonStart`.
- `holdJoy`: once `joyPressReq` s have passed since the press, the run strobes `hit`, logs
  `timing.joyHoldReqMet` and plays the high tone. A release before then strobes
  `joyRelease` and `miss` and plays the low tone.
- `hit`: `pds.deliverReward`, then the trial ends.

The other declared states (`dontMove`, `makeDecision`, `cr`, `fa`, …) are never entered.

## Conditions

There is no trials array. `nextParams` draws
`joyPressReq = joyPressReqMin + (joyPressReqMax − joyPressReqMin)·rand` and copies it to
`p.status.joyPressReq` for the GUI. The default min and max are both 0.1 s, so the hold
is fixed until the experimenter changes them in the GUI.

## Key trVars

The GUI shows `rewardDurationMs` (280), `joyPressReqMin` / `joyPressReqMax`,
`wantEndFlicker` and `passJoy` / `passEye`, plus leftover stimulus variables. The single
settings file is `joystickPress_settings.m`. The rig config is chosen from the hostname
(`rigConfig_rig<N>`).

## Data & strobes

- `p.trData.timing`: `joyPress`, `joyRelease`, `joyHoldReqMet`, `reward`, `trialBegin`,
  `trialEnd`, and flip times. `trialEndState` gives the outcome.
- strobeList (built as `fliplr({expression, codeName; …})`): `date_1yyyy`,
  `date_1mmdd`, `time_1hhmm`.
- `_finish` calls `pds.waitForJoystickRelease` and `postTrialTimeOut` before the next trial.
